# ☕ Coffee Shop Sales Dashboard (Excel)

This project is a **dynamic Excel dashboard** built to visualize and analyze sales data from a coffee shop. It provides actionable insights into sales performance, customer behavior, and product trends using interactive charts and KPIs.

---

## 🔍 Features

- 📅 **Time-Based Trends**:
  - Sales and footfall by weekdays
  - Quantity ordered based on hour of day

- 📊 **Sales Insights**:
  - Total Sales and Footfall KPIs
  - Avg Bill/Person and Avg Orders/Person

- 🍩 **Product and Category Analysis**:
  - Top 5 selling products
  - Category-wise and size-wise sales distribution

- 📌 **Design**:
  - Clean, pastel-colored visual theme
  - Interactive elements for better interpretation
